# Sunfire Arena

A fast horde-shooting arena game that runs in the browser (three.js).

**Play:** https://ooglux-ops.github.io/sunfire-arena/

Keyboard and mouse required. WASD to move, mouse to aim and fire, Space to jump, Shift to dash, 1/2/3 to switch weapons, 4 or Q for the sidearm (unlimited ammo), Esc to pause (mouse and volume settings are there too).

Each arena downloads only the models it needs, and the 3D engine and fonts are served from this repo, so the game has no outside dependencies.
