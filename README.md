# Sunfire Arena

A fast horde-shooting arena game that runs in the browser (three.js).

**Play:** https://ooglux-ops.github.io/sunfire-arena/

Keyboard and mouse required. WASD to move, mouse to aim and fire, Space to jump, Shift to dash, 1/2/3 to switch weapons, Esc to pause.
